## 一、怎么确认「申请成功了没有」

五项申请各自在哪看、看到什么算成功——按这张表点进去就行，**看到对应状态截个图发我**，我接着往下做。

| # | 申请 | 在哪看（点哪几级菜单） | 成功长什么样 | 还在审 / 失败长什么样 |
|---|---|---|---|---|
| 1 | **微信认证**（30 元，已付） | mp.weixin.qq.com 登录 → 左侧「设置」→「基本设置」→ 往下找「微信认证」卡片 | 显示「**已认证**」，旁边有证书/详情按钮，能点开看认证时间 | 「审核中」「未通过（附驳回原因）」 |
| 2 | **小程序备案** | 同样走「账号设置 → 基本设置」，在「微信认证」下方有「**小程序备案**」卡片 | 显示「**已通过**」，并给出备案号，形如「粤ICP备2026xxxxxx号-1X」 | 「平台审核中」「管局审核中」「已驳回」（会写明原因） |
| 3 | **用户隐私保护指引** | **左下角头像/「兰欧茜」→ 账号设置 → 基本设置 → 往下拖找「服务内容声明」→ 用户隐私保护指引 → 去完善** | 状态「**已生效**」，能看到填写的内容与生效日期 | 「审核中」「未通过」 |
| 4 | **微信支付商户号** | pay.weixin.qq.com 登录 → 首页顶部 / 「账户中心」→「商户号管理」 | 看到一串**8–10 位数字的商户号**（16x 开头），状态「已开通」 | 「审核中」「待补充资料」「被驳回」 |
| 5 | **云开发环境**（已开通，19.9 元/月） | 开发者工具点「云开发」→ 概览，或 mp 后台「开发管理 → 云开发」 | 环境 ID `cloud1-d7gvr1q2x22eb4eb0`，状态「正常」 | 显示「环境不可用」「欠费」 |

**另外两项容易漏的：**

- **AppID 和商户号绑定了没有**：pay.weixin.qq.com → 「产品中心」→「AppID 账号管理」，看 `wx37e1073cc15df404` 在不在列表里。不在就点「关联 AppID」，回到 mp 后台同意即可。**这一步不做，后面写支付代码也调不起来。**
- **备案号下来后要填类目**：mp 后台「设置」→「基本设置」→「服务类目」，选「电商平台 / 服装鞋帽」，需要上传营业执照。

> 备案在管局那边最长 20 个工作日，期间「管局审核中」就是正常状态，不用管。
> 认证/备案/商户号**都不要重复提交**，重复提交会把前面的排到队尾。

## 三、还差什么

### A. 我来做（不需要你动手）

1. 上传体验版 **v1.3.0**（30 款商品 + 实拍图），重新出二维码。
2. 文档和报告升到 v1.3（数字 108 / 132、30 款、21 所学校）。
3. **支付对接代码**：拿到商户号后加 `requestPayment` + `payNotify` 验签，把演示支付换成真支付。
4. 发货/退款通知（订阅消息）——店长发完货，家长收到微信通知，可选。
5. 商品图从包里搬到云存储（现在 601 KB 在包里，主包 2 MB 上限，再加图就紧了）。

### B. 你要做（我做不了，都要你本人/妈妈出面）

1. **等备案**：管局审核中，通过后把备案号截给我。
2. **填隐私保护指引**（上面第 3 项，10 分钟）。
3. **商户号**：把申请表填完，需要妈妈扫脸 + 她的借记卡；拿到商户号发我 8–10 位数字。
4. **让妈妈扫码进体验版**：她打开小程序后，随便点一下「我的」，我在后台就能拿到她的 openid，写进 `admins`，她就直接是店长（不用口令）。
5. **真机走一遍**：下单 → 支付（演示）→ 店长发貨 → 收货 → 退货，看有没有卡的地方。

### C. 等外部结果

- 备案号（管局，最长 20 个工作日）
- 商户号审核（1–5 个工作日）
