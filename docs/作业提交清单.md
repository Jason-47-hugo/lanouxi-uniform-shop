## 三、备案被驳回怎么处理（按顺序做）

驳回一定会给出**「审核意见」**，先看清楚是哪一条。常见的五类：

| 驳回原因原文大概长这样 | 怎么改 |
|---|---|
| 「主体名称与营业执照不一致」 | 主体名称要**一字不差**照抄执照，包括「（个体工商户）」和括号全半角 |
| 「通讯地址与营业执照不符」或「地址不详」 | 通讯地址填执照上「经营场所」原文；没有门牌号的在备注写清楚 |
| 「服务内容与实际业务不符」 | 只勾「批发和零售业 → 零售批发（匹配项）」，别多勾 |
| 「主体负责人信息有误/无法核实」 | 主体负责人必须是**执照上的经营者（妈妈）**，身份证正反面 + 她本人的手机号，管局会打电话 |
| 「小程序名称/简介不符合规范」 | 名称「兰欧茜」可以；简介不要写「最」「第一」「官方」，不要带电话微信 |

改完**重新提交**即可，不用重新认证（认证 2026-11-22 已通过）。
管局审核最长 20 个工作日，**但作业提交不需要备案号**，别为它等。

## 四、隐私保护指引在哪（这个版本的后台）

你这个后台左边的菜单是：首页 / 管理 / 数据 / 基础功能 / 支付与交易 / 行业能力 / 推广与搜索 / 开发与服务 / 小程序码 / 通知中心 —— **没有「设置」这一项**，因为「设置」藏在**左下角**：
鼠标移到左下角你的头像/「兰欧茜」上面 → 点「**账号设置**」→ 左侧出现「设置」类菜单 →「**基本设置**」→ 页面往下拖，找「**服务内容声明**」→ 里面就是「**用户隐私保护指引 → 去完善**」。

官方文档原文的入口写法是「账号设置 - 服务内容声明 - 用户隐私保护指引 - 去完善」，见
[微信开放文档 · 用户隐私保护指引填写说明](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/)。

备选入口（同一处内容）：**管理 → 版本管理 → 提交审核**页面，滑到最下面有「用户隐私保护指引设置 → 点击更新」，点它也能进。

填的时候只勾三项，别多勾：

- 收货地址（用于发货）
- 相册/相机（用于店长换商品图）
- 订单信息（用于售后查询）

位置、通讯录、设备信息、剪贴板**一个都不要勾**——勾了就要写更长的说明，还容易被拒。
