## 仓库设置建议

- 仓库名：`lanouxi-uniform-shop`（或你定的英文名）
- 可见性：**Public**（老师要能点开）
- 不要勾选「Add a README」（本地已有）
- 上传方式：网页「Add file → Upload files」拖整个文件夹，或 GitHub Desktop
- `.gitignore` 建议加上：`node_modules/`、`*.backup-*`、`preview/html/`（构建产物，可再生成）、`web/`（可再生成）、`docs/brand-options/`（选型草稿，可选）

> 注意：`.gitignore` 里**不要**排除 `cloudfunctions/api/data/products.json` 和 `cloudfunctions/seed/`，否则别人克隆下来跑不起来。
